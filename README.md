## 🛠️ Installation et Lancement

Le projet utilise **uv** pour la gestion rapide des dépendances.

1. **Installer les dépendances** :

    ```bash
   uv sync
    ```

2. **Lancer l'application** :

    ```bash
   uv run app.py
    ```

L'application sera accessible sur http://127.0.0.1:8050/.
